Can I explore my own repository?

Yes. Enter a public GitHub repository above, or choose a local folder, files, webpage or text in the app. Complete eligible-source indexing is the default, with 24 bundled syntax grammars, incremental file reuse and project-aware references. JavaScript/TypeScript also uses the compiler symbol table; Julia preserves possible method targets as marked candidates. The coverage report separates source collection, syntax errors, unresolved semantics and preview excerpts. Large maps expand progressively without deleting analysis data.

What if a URL cannot be read?

Check that the repository is public and the URL points to a repository or subtree. GitHub rate limits and browser CORS rules can prevent remote reading. You can select a local checkout instead, or use skylense open ./project with the downloadable toolkit. Read the source guide.

Is this a native macOS app?

This release is a browser app with offline HTML, plus a local Node.js toolkit. A native macOS installer is not available yet.

Is Skylense open source?

Skylense is available as a downloadable application preview. Source licensing and commercial rights remain reserved. The attributed examples, bundled parsers and compiler retain their upstream licenses. Read the preview notice.

What happens to an imported model?

Models stay in the current browser session. Syntax facts and verified public GitHub file bytes are cached locally to speed up repeat analysis; selected source files are not uploaded. The local MCP process reads requested public URLs and source files inside an explicitly configured root. Connected agents receive query results according to their own data policies. Read the data boundaries.

What language is the interface?

The preview's interface is primarily Chinese, with source symbols in their original language. This site and the getting-started guides are available in English; a Chinese README is also provided.
