Can I explore my own repository?

Yes. Choose Open source to select a folder or files, enter a public GitHub URL or webpage, or paste text. Python/JS/TS receive lexical declaration and import analysis; other formats keep hierarchy and available text or metadata. Coverage is bounded and reported. Browser CORS restrictions can be handled with the local CLI.

Is this a native macOS app?

This release is a browser app with offline HTML, plus a local Node.js toolkit. A native macOS installer is not available yet.

Is Skylense open source?

Skylense is available as a downloadable application preview. Source licensing and commercial rights remain reserved. The attributed example materials retain their upstream licenses. Read the preview notice.

What happens to an imported model?

Web imports stay in the current browser session. The local MCP process reads requested public URLs and source files inside an explicitly configured root. Connected agents receive query results according to their own data policies. Read the data boundaries.

What language is the interface?

The preview's interface is primarily Chinese, with source symbols in their original language. This site and the getting-started guides are available in English; a Chinese README is also provided.
