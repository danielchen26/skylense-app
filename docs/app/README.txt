Skylense — Web preview

Open standalone.html for the offline workbench, or serve this directory with a local static HTTP server and open index.html.

Choose autoresearch, LangGraph or vLLM in the sidebar. These are curated public-source snapshots at pinned commits, with short excerpts and authored guides. They are not exhaustive repository maps or measured runtime traces. See EXAMPLE_NOTICES.md.

Use Themes for six appearances. Use Connect for local Agent and terminal instructions. The Web package does not itself run an MCP server or terminal; those are in the separate Skylense Agent toolkit or source checkout.

JSON imports are parsed locally. Export a model before switching examples or reloading to retain it. See PRIVACY.md for storage and connected-Agent data boundaries.

This package contains public examples only. It excludes repository history and private working documents. macOS packaging is a separate step.
