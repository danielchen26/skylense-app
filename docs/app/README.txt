Skylense 0.3 — Complete Web workbench

Open standalone.html, or serve this directory and open index.html.
Choose Open source / 打开来源 to select a folder or files, paste text/HTML, or enter a public GitHub repository/webpage URL. Review the coverage report before entering the map. Browser files stay local. Export model JSON to retain it after reloading.

Direct URL reading is subject to browser CORS. For blocked public webpages, use the separate Node.js toolkit: skylense open https://example.com, or upload a saved HTML page. The toolkit includes this same full workbench.

Automatic analysis is bounded static source reading, not execution or a complete call graph. Python/JS/TS imports and declarations, document headings/links, generic text previews and binary metadata are distinguished. See guides/SOURCES.md and PRIVACY.md.

Themes, layers, animated orthogonal relationships, source previews, context, routes, comparisons, saved views, presentation and exports work with imported/generated models. Curated autoresearch/LangGraph/vLLM examples remain available; EXAMPLE_NOTICES.md preserves attribution. NOTICE.md describes preview-use permission; Skylense is not released under an open-source license.
